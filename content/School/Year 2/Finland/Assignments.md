# Main assignment
[[School/Year 2/Finland/Textile and Circular Economy|Document]]
This weeks assignment consists of 3 elements:
- The team will give a suggestion of what kind of a digital solution the project should use for the container.
- The team will think about what kinds of information the digital solution should contain
- The team will create a campaign to create public awareness for the upcoming end-of-life textile recycling container

Use your creativity and remember to give arguments for your decisions in the presentation!!!

>[!note] Digital solution for the container
> - The digital solution which will be on the container
> - Users are citizens of different ages
> - Budget 5.000 euros
> - If you find a smart container with a digital system, the budget is then 15.000 euros
> - Specify in your presentation which solution; on container or smart container which includes digital tools

>[!note] what the digital solution should contain
>- The aim is that it will be guiding citizens **to recycle** end-of-life textile and to **recycle correctly**
>- Needs to be user friendly
>- 20.000 euro budget

>[!note] Campaign for the upcoming end-of-life textile recycling container
>- Reaistic material which scould be used in the project
>- Material can be used in the printed media but also in the social media
>- Language: English, Finnish and Russian, if you have time, others is okay
>- Use the SustainaCycle Logo!!!
>- Tip: use story-telling
>- 5.000 euro budget

>[!important]
>- Money can be shared between pools, but try to keep the budget in beween brackets
>- Make it visually pleasing, simple but attractive

# Systems thinking
[[School/Year 2/Finland/Systems Thinking|Document]]
>[!important] For the case study (part 1)
>- Write down every stakeholder in your system on a blank piece of paper. Push yourself to think past the obvious.
>- Add any technologies or objects that are relevant. Again, push past the obvious.
>- Draw arrows between the different parts of your system to identify how they’re connected
>	- Are there casual loops or other feedback loops?
>- Reflect on what specific areas you want to examine more closely. What questions come up for you? What gaps do you see?
>
>Tomorrow:
>- Explore which SDGs are relevant to the case
>	- The obvious and the less obvious
>	- What are the inter-linkages
>- How does your proposed solution affect these SDGs?

>[!important] For the case study (part 2)
>- Define the problem
>- Analyse the problem using the systems iceberg
>- Brainstorm solutions using the systems iceberg
>- Evaluate solutions using the solutionary scale
