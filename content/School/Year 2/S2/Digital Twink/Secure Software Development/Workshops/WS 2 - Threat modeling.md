# Intro
Threat modeling is the creation of a diagram that shows all the threats in the functionality and communication between systems/applications. It is an iterative process, meaning it constantly changes and updates according to its system.

The iterative process looks like this:
- Define the scope of security requirements
- Model the diagram of the system
- Identify the threats
- Mitigate the threats
- Validate the mitigation
