# Intro
Making software or applications usually means you have to use external or third party libraries, resources or anything similar. These third party components may become compromised or have a vulnerability in them. A software component analysis (SCA) is an automated process that identifies and manages open-source and third party within software.

# What it does
SCA scans your code base for vulnerabilities associated with third party parts of that code base. It does this fully automatic.
- It identifies third party components
- Detects vulnerabilities
- Ensures license compliance in case open-source software needs it
- Assesses the risk of the vulnerabilities and makes suggestions on how to mitigate it
- Offers CI/CD intergration and monitors
- Generates SBOMs (Software Bill of Materials), a list of all software components and their dependencies

Using SCA will enhance the security of an application without the need to manually audit the software.
