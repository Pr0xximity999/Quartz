# Inhalen
Als je wilt inhalen moet je op 2 dingen erg goed letten:
- Maak je voldoende snelheid?
- Is er genoeg ruimte?

Gebruik je knipperlicht om aan te geven dat je inhaalt en blijf niet onnodig links rijden. 

# Inhaalverboden
>[!info]- Verkeersbord RVV F01 Inhaalverbod Motoroertuigen
>![[Vault-data/Attachments/12 - Inhalen inhaalverbod.png]]
>Geen enkel motorvoertuig mag hier inhalen, tenzij je een brom- of snorfiets inhaalt

>[!info]- Verkeersvord RVV F03 Inhaalverbod Vrachtauto’s
>![[Vault-data/Attachments/12 - Inhalen inhaalverbod vrachtautos.png]]
>Vrachtauto’s mogen hier niet andere automobilisten inhalen

Je mag nooit inhalen bij:
- Een doorgetrokken streep, uitzondering van de spitsstrook
- Vlak voor een bocht
- Vlak voor een verkeersdrempel
- Vlak voor een kruispunt
- Voor of op een zebrapad
- Op een verdrijvings- of puntvlak
- Als je zelf word ingehaald
- Als een tegenligger ook aan het inhalen is.

>[!important] Je mag van rechts inhalen bij F.R.U.I.T
>- File
>- Rotonde
>- Uitvoegstrook
>- Invoegstrook
>- Tram

>[!important]
>Als een auto links voorgesorteerd staat om af te slaan, maar voorrang moet geven aan tegemoetkomend verkeer, dan mag je (zolang er ruimte is) van rechts inhalen

>[!note] Motorrijders in de file
>Motorrijders mogen in de file tussen de auto’s passeren. Let hier dus goed op.
>Wijk uit zodat de motorrijder kan passeren.
