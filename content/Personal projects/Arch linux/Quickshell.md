[[https://quickshell.org/|Quickshell]] is a toolkit you can use to create status bars, widgets, lockscreens and everything else desktop related. It uses the QtQuick qml framework.

# QML fundamentals
QML, or Qt Meta-object Language) is a user interface markup language. I would describe it to be a weird mix of JSON and JavaScript.

QML is made for designing user interface-centric applications.
