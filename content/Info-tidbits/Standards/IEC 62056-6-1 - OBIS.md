# Description
The OBIS, or OBject Identification System, is a code that corresponds to device readout values of an electricity meter. It is the successor of the EDIS, or Energy-guided DIffusion Sampling, code.

IEC 62056 in itself is a handful of standards targeted at the data exchange of electricity meters. See the [Wikipedia page](https://en.wikipedia.org/wiki/IEC_62056) for the list of all the containing standards.

# Code anatomy
The OBIS code consists of (up to) 6 sub-identifiers marked by the letters A to F. Whether one or more are present is optional. The way sub-identifiers are identified is by the separators used: `A-B:C.D.E*F`.
- `A`: Medium
	- `0`: Abstract objects
	- `1`: Electricity
	- `4`: Heat cost allocator
	- `5/6`: Thermal energy/heat
	- `7`: Gas
	- `8`: Cold water
	- `9`: Hot water
	- etc…
- `B`: Channel. Specifies the device or communication channel
	- `0`: Typically the main meter
	- `1`: Some secondary device like a gas meter
		- This can make gas values appear as `0-1` instead of `7-0` in some cases.
- `C`: Physical value 
	- `1`: Energy
	- `2`: Power
	- `3`: Current
	- `4`: Voltage
	- `5`: Power factor
	- `7`: Current (instant) power, the current usage
	- `8`: Cumulative energy
	- `24`: Gas/Water measurement object
	- `96`: Metadata
- `D`: Measurement type defined by groups `A` to `C`. Some common values are:
	- `0`: Total
	- `1`: Import (consumption)
	- `2`: Export (production)
- `E`: Measurement type defined by groups `A` to `D`
- `F`: Separates the results
